## 價值

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 使用價值 | use value | 物的性質滿足人的需求而產生的價值；一切價值的起源 |
| 商品（市場）價值 | commodity / market value | 透過交換、由另一物表現出來的價值 |
| 交換價值 | exchange value | 以 A 換 B 時，A 對我產生的價值 |
| 異化 | alienation | 一物的價值由「不是它自己」的東西來表現 |
| 基本價值 | | 勞動以使用價值呈現：樂在工作本身 |
| 附加價值 | | 追求基本價值、做到出類拔萃後，隨之而來的金錢名聲 |

## 倫理學分類

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 規範倫理學 | normative ethics | 問「我應該做什麼？」，尋找判斷行為的準則 |
| 德行倫理學 | virtue ethics | 問「我應該成為什麼樣的人？」，重視品格 |
| 動機論 | | 依動機的善／惡（good/evil）評價行為 |
| 結果論 | consequentialism | 依結果的對／錯（right/wrong）評價行為 |

## 利己與利他

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 心理利己主義 | psychological egoism | 描述：所有人類行為都出自自我關懷 |
| 倫理利己主義 | ethical egoism | 規範：每個人都應該提升自己的利益 |
| 自我關懷的 | self-regarding | 中性詞，不同於帶貶義的「自私」 |
| 自私的 | selfish | 帶有不道德意涵 |
| 享樂主義 | hedonism | 快樂是人生目的；指持續的快樂，不是放縱 |
| 自利 | self-interest | 《國富論》：理性的利己 |
| 自愛 | self-love | 《道德情操論》：發展為對德行與真正榮耀的愛 |
| 自我保存 | self-preservation | 自愛的基礎 |
| 同情、憐憫 | sympathy, compassion, pity | 透過想像力設身處地而產生的情感 |
| 公正的旁觀者 | impartial spectator | 道德原則從旁觀者的讚許中形成 |
| 利他主義 | altruism | 利他才是人性本質；有意圖、不求回報 |
| 有效利他主義 | effective altruism | 辛格：結合效益主義與利他主義的道德勸說實踐 |

## 效益主義

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 效益主義 | utilitarianism | 最大多數人的最大幸福是是非的尺度 |
| 邪惡利益 | sinister interests | 邊沁：統治的少數人與大眾福祉衝突的利益 |
| 簡便原則 | rules of thumb | 彌爾：緊急時依經驗慣例行動，最終仍受效益原則檢驗 |
| 平等原則 | | 每個人只能被當作一個人計算 |
| 超義務行為 | supererogatory act | 超出義務要求的善行；效益主義難以解釋 |

## 康德

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 義務論 | deontology | 道德價值取決於是否出於義務 |
| 善意志 | good will | 唯一無條件的善；依道德要求選擇行為的意識傾向 |
| 準則 | maxim | 決定行為的主觀原則，顯示行為動機 |
| 定言令式 | categorical imperative | 無條件的道德命令：「你應該……」 |
| 假言令式 | hypothetical imperative | 有條件的命令：「如果想要……就……」 |
| 自律 | autonomy | 道德法則由自己的理性訂立；自律即自由 |
| 他律 | heteronomy | 被外在條件推動的行為 |

## 德行倫理學

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 德行 | virtue | 藉由習慣養成的行為傾向 |
| 傾向 | disposition | 在某種情境下習慣性展現某些行為 |
| 中庸 | the mean | 介於過與不及之間，需不斷校準 |
| 實作 | practice | 社會合作建構的、複雜而一貫的活動形式 |
| 內在的善 | internal good | 透過追求活動本身的卓越而實現的善 |
| 外在的善 | external good | 活動之外的獎勵，例如糖果、金錢 |
| 四因說 | four causes | 形式因、質料因、動力因、目的因 |
| 不動的推動者 | the unmoved mover | 動力因追溯的最終起點 |

## 懷疑、存在主義與現象學

| 中文 | 英文 | 一句話解釋 |
| --- | --- | --- |
| 蓋吉的戒指 | the ring of Gyges | 葛勞康的思想實驗：不受懲罰的人會怎麼做 |
| 零和賽局 | zero-sum game | 一方所得等於另一方所失 |
| 道德相對主義 | moral relativism | 道德法則因社會而異 |
| 在己存在 | being-in-itself | 物、身體：充實，就是它自己 |
| 對己存有 | being-for-itself | 意識：虛無，可以被填滿 |
| 存在先於本質 | existence precedes essence | 先存在、行動，再定義自己 |
| 此在 | Dasein | 海德格：能理解存有的人的存有 |
| 屬我性 | in each case mineness | 存有屬於我自己 |
| 本真存有 | authentic being | 堅守存有的可能性屬於自己 |
| 決斷 | resoluteness | 讓人回到本真存有的行動 |
| 參與 | participation | 高達美：開放自己、與存有合一 |
| 充實時間 | full-filled time | 在參與中充分理解事物的時間 |
| 空洞時間 | empty time | 與充實時間相對的時間 |
