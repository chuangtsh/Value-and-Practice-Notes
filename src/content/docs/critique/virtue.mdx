<p class="lead">德行倫理學不問「我應該做什麼」，而問「我應該成為什麼樣的人」。它的關鍵是：什麼樣的人，就會傾向做什麼樣的事。</p>

## 和規範倫理學有什麼不同？

| | 規範倫理學 | 德行倫理學 |
| --- | --- | --- |
| 核心問題 | 我應該**做**什麼？（What shall I do?） | 我應該**成為**什麼樣的人？（What shall I be?） |
| 關注 | 判斷行為是否道德的**準則** | 行為者的**品格** |
| 代表 | 利己主義、利他主義、效益主義、義務論 | 亞里斯多德、麥肯泰爾 |
| 中國哲學對照 | | 儒家的君子與小人之別 |

德行倫理學認為，道德問題不在於用哪些準則判斷行為，而在於「什麼樣的人會傾向做什麼樣的事」。它在當代已成為不可忽視的倫理學派。

## 亞里斯多德

亞里斯多德把「幸福」定義為「**一種與完善美德相符合的心靈實踐活動**」。所以修養德行才能過上幸福的生活，道德是幸福生活的必要條件，培養德行也就成了他倫理學的重點。

### 德行的四個特點

1. **德行是後天學習養成的習慣**
   德行是一種藉由習慣養成的行為傾向（disposition）。它不是天生的氣質，但可以靠後天培養。有德之人在某種情境下會**習慣性地**展現某些行為，而不是靠感覺或思考來決定。養成德行不能偶一為之，必須不斷努力、反覆實踐，需要時間、毅力和恆心。
   > 我們由於實行正義的行為，才成為正義的人；實行節制的行為，才成為節制的人；實行勇敢的行為，才成為勇者。
2. **德行是自願的行為**
   德行意味著謹慎抉擇後的行動，是理智和意志合作下的自願行為。
3. **德行在於合乎中庸**
   德行介於「過」與「不及」之間。例如勇敢介於怯懦和魯莽之間，慷慨介於吝嗇和浪費之間。
4. **德行必須付諸實踐**
   > 藉著建築而成為建築師，彈奏七弦琴而成為音樂家；同樣地，實踐正義的行為才能成為正義的人。

:::tip[課堂筆記・判斷一個人是否有德]{icon="pencil"}
1. 看他有沒有**長期而穩定的行為習慣**；
2. 習慣可以被培養嗎？怎麼培養？

### 課堂補充：亞里斯多德的形上學背景

這部分講義沒有，是 9/29 課堂上為了說明「德行」而補充的背景。

:::tip[課堂筆記・人與德行]{icon="pencil"}
- 亞里斯多德：「人」是有**理性**、有良心的動物。
- 「好人」的「好」是形容詞，是一種**依附體**（就像「白」、「一」），必須依附在「人」這個**載體**上。
- 靈魂（soul）的品質有高低，就是 virtue；靈魂透過身體（body）表現為行動（action），行動再回頭養成靈魂的品質。
:::

:::tip[課堂筆記・四因論]{icon="pencil"}
| 四因 | 意義 | 筆記中的說明 |
| --- | --- | --- |
| 形式因 | 事物「是什麼」的結構 | 原子組合的規則 |
| 質料因 | 事物由什麼構成 | 原質（prime matter）；原子（Atom）不可再分割 |
| 動力因 | 什麼使它運動、變化 | Aₙ → … → A₃ → A₂ → A₁，追溯到「不動的推動者」（the unmoved mover）；生命體的動力是靈魂 |
| 目的因 | 它為了什麼而存在 | 善（goodness）；分人造物與自然物（人／非人） |

神學後來藉由亞里斯多德的形上學論證上帝存在：上帝創造原子、給予動力。所以「哲學的神」是可以合理論證的。
:::

:::tip[課堂筆記・論靈魂諸說]{icon="pencil"}
| 存在 | 靈魂的能力 |
| --- | --- |
| 無生物 | 沒有靈魂 |
| 植物 | 植物魂：生長 |
| 動物 | 動物魂：生長 + 運動 |
| 人 | 人魂：生長 + 運動 + **理性（思考）** |

所以蘇格拉底說：不經思考的人生不值得活。
:::

## 麥肯泰爾：實作與內在的善

麥肯泰爾（Alasdair MacIntyre，《德行之後》*After Virtue*）認為，西方倫理學關於「德行」的討論有一個共同的核心概念：**實作**（practice）。

**實作**是任何由人類社會合作建構的、複雜而一貫的活動形式。它有兩個特徵：

1. 實作是**社會建構的合作性活動**；
2. 透過追求這個活動的**最佳標準**，可以實現它的**內在的善**。

### 什麼是「內在的善」？阿光下圍棋

<GoodsTimeline />

阿光一開始不懂圍棋，也不想學。爺爺為了鼓勵他，約定每天陪爺爺下一小時棋就給一顆糖。時間從一小時增加到兩小時，糖也跟著變多；後來阿光開始和別人對弈，獎勵改成零用錢。這個時期，下圍棋只是為了糖果或零用錢，是**外在的善**。

有一天阿光贏了一盤棋，爺爺正要掏錢，阿光卻說：「不用了！贏棋我就滿足了，能下棋我覺得很幸福！」這是**內在的善**。於是阿光立志把棋藝磨練到神乎其技的境界，雖然辛苦，卻樂此不疲。

:::tip[課堂筆記・9/29]{icon="pencil"}
- 人類的道德活動，是**合作性的實作活動**。
- inner good ✓：個人的道德價值；external good ✗。
- 德行是靠外在價值（物質或精神）**逐漸**建立內在價值的過程。
:::

:::note[和第一週的連結]
阿光的故事和[第一週](/value/what-is-value/#工作賺錢錯了嗎)的「基本價值 vs. 附加價值」是同一個結構：樂在活動本身（內在的善／基本價值）才是重點，獎勵（外在的善／附加價值）不能本末倒置。
:::

### 任何實作都需要的三種德行

麥肯泰爾指出，任何實作都需要**正義、勇氣、誠實**。因為實作要求參與者之間有某種關係，這三種德行就是參與者共享的標準。（講義提醒：這只是麥肯泰爾個人的看法，不一定只有這三種。）

### 實作不是技藝，也不是制度

1. **實作不只是技術性的技藝。** 圍棋這個實作不只是下棋技巧，還包含圍棋的精神和意義。
2. **實作不是制度。** 下棋、做實驗是實作，圍棋教室、實驗室只是制度。我們應該在實作中追求、培養德行，而不是被制度限制。

例如醫生的德行在於解除病人的痛苦。如果為了顧及醫學院教授的面子而隱瞞誤診，就是制度凌駕於實作之上，違反了德行倫理學。（電影《孤高的手術刀》）

## 總結：兩種倫理學互補

西方倫理學界對規範倫理學和德行倫理學孰優孰劣爭論不休。老師的看法是：

> 只有人格特質而缺乏行為準則，是**盲目**的（德行倫理學）；只知道法則而缺乏人格特質，則是**無能**的（規範倫理學）。

這也是孔子強調道德實踐必須「**仁**」、「**智**」兼具的理由。

## 自我檢測

<details class="quiz">
<summary>1. 為什麼亞里斯多德說德行是「習慣」而不是天性？</summary>

因為德行要靠反覆實踐才能養成，就像建築師要靠建築、樂手要靠彈奏一樣。有德之人在情境中會習慣性地做出正確行為，而這種傾向是後天培養的，不是天生的。

</details>

<details class="quiz">
<summary>2. 中庸是不是「取兩個極端的正中間」？</summary>

不是。中庸是在特定情境中最適切的做法，而且要在實踐中不斷校準修正。例如面對危險時的勇敢，不等於「一半怯懦加一半魯莽」。

</details>

<details class="quiz">
<summary>3. 用麥肯泰爾的概念分析：一個學生只為了獎學金念書，後來愛上研究。</summary>

一開始追求的是外在的善（獎學金），後來在研究這個實作中體會到內在的善（追求知識本身的卓越與滿足）。外在的善可以是入門的誘因，但德行是在追求內在的善的過程中養成的。

</details>

<details class="quiz">
<summary>4. 老師說德行倫理學「盲目」、規範倫理學「無能」，是什麼意思？</summary>

只有好品格而沒有準則，不知道具體該怎麼做，所以盲目；只有準則而沒有好品格，知道該怎麼做卻沒有去做的動力，所以無能。兩者要互補，就像孔子要求仁智兼具。

</details>
